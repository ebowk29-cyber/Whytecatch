# Whyte Catch Tilapia Hub

A single-file sales management app for a tilapia business: record sales, track stock, customers who owe you, expenses, and profit reports. Works on phones and computers.

## Run it
Open `index.html` in a browser, or host it free with GitHub Pages (Settings > Pages > Deploy from branch > `main` / root).

## Notes
- Records are saved in the browser on the device you use. They do not sync between devices.
- Use **Shop setup > Download backup** often, and **Restore from backup** to move records to another device.
- Fonts load from Google Fonts. Without internet it falls back to system fonts.
